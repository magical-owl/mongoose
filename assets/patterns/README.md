# Pattern Background Assets

These wallpaper tiles are project-authored raster assets generated by `scripts/generate-owned-assets.js`.

## Files

- `pattern-spring.png` - simple blossoms, leaves, and small bee-like accent shapes.
- `pattern-summer.png` - simple suns, waves, and ice cream shapes.
- `pattern-autumn.png` - simple leaves, pumpkins, and acorn shapes.
- `pattern-winter.png` - simple snowflakes, fireplace, and scarf shapes.

## Provenance

- Source: `npm run generate:owned-assets`.
- Generator: `scripts/generate-owned-assets.js`.
- Inputs: no third-party images, stock references, AI image references, brand marks, text, copyrighted characters, people, or named artist style targets.
- License intent: project-authored original assets for this app.
- Attribution: none required by the project-authored generation process.
- Release status: draft until human IP/design review is completed.

## Release Notes

These are intentionally simple placeholder patterns. They are meant to reduce provenance risk while the final visual direction is unsettled. Final release patterns should either keep this deterministic generation path or use original human-designed references with source files recorded in `assets/ASSET_REGISTER.md`.
